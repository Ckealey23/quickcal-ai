QuickCalAI

Add calendar events and tasks from any webpage by typing, speaking, or selecting text.

QuickCal reads what you type or select, uses AI to turn it into a calendar event or Google Task, and can save it for you.

Connect Google so QuickCal can create and update events on calendars you own, create tasks in your default Google Tasks list, see which calendars are available, and check for conflicts. Google’s permission prompt starts only after you click Connect.

Typed and selected text is sent to QuickCal’s AI parser. Uploaded documents are analyzed remotely. If you use voice, recorded audio is sent for transcription. QuickCal does not keep all of that processing on your device.

QuickCal is ready

Pin QuickCalAI from the Chrome toolbar puzzle icon, then click the QuickCalAI icon on a normal webpage to open the input bar.

  • Type: “Coffee with Alex tomorrow from 10 to 10:30 AM” and press Enter.
  • Tasks: “Remind me to submit my report tomorrow” creates a Google Task.
  • Voice: use the microphone in the bar, then submit the recording.
  • Highlight: select event text on a page, then choose “Add to QuickCal”.

A complete single-event or task request can create it automatically. Multi-event selections and document analysis open a review list first so you can choose what to save.
